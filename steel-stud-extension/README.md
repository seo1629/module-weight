# 스틸 스터드 배치 도구

CAD로 만든 스터드 단면(2D 형상)을 압출해서, 지정한 간격으로 자동 배치하는 SketchUp 확장 프로그램입니다.

**"모듈러 중량 Exporter"와는 완전히 별개의 확장 프로그램**입니다 — 서로 설치 여부와 무관하게 각자 독립적으로 동작합니다. 다만 생성된 스터드에는 `modular_weight`라는 같은 이름의 속성(AttributeDictionary)으로 role/Tag/계산기준을 기록해두기 때문에, 모듈러 중량 Exporter가 함께 설치되어 있으면 생성 직후 바로 검증·내보내기 대상이 됩니다.

## 설치

1. `Extensions → Extension Manager → Install Extension`
2. `steel_stud_placer.rbz` 선택
3. SketchUp 재시작
4. 메뉴에 `Extensions → 스틸 스터드 배치 도구`가 보이면 설치 완료

## 사용 순서

1. CAD(dwg/dxf 등)에서 만든 스터드 단면을 `File → Import`로 SketchUp에 가져와 **바닥(XY 평면, Z=0 근처)에 눕혀서** 배치
2. 그 단면 그룹/컴포넌트 선택
3. `🏗️ 스틸 스터드 배치` 실행
4. 순서대로 입력: 높이(mm) → 간격(mm, 기본 450) → 공종 → Tag(비워도 됨)
5. 3D 화면에서 배치선의 시작점 → 끝점 클릭
6. 완료 — 지정한 간격으로 스터드가 자동 배치되고, `role=PART`, 계산유형=LENGTH까지 자동 지정됩니다

## 알려진 한계 (v1)

- 벽 방향에 맞춰 단면을 자동으로 회전하지 않습니다 (무게 계산에는 영향 없음, 시각적 방향만 관련).
- 배치선은 수평(양 끝 높이가 같음)이라고 가정합니다.
- 실제 SketchUp에서 아직 테스트되지 않았습니다. 간단한 사각형 단면으로 짧은 구간부터 먼저 테스트해보세요.
