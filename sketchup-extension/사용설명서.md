# 모듈러 중량 Exporter 사용설명서

SketchUp에서 모델링한 부재의 물량(면적/체적/길이/개수)을 자동으로 계산해서, 웹 중량 계산기에 올릴 JSON 파일로 내보내는 도구입니다.

---

## 1. 설치

1. 받은 `modular_weight_exporter.rbz` 파일 확인
2. SketchUp에서 `Extensions → Extension Manager` 열기
3. **Install Extension** 클릭 → `modular_weight_exporter.rbz` 선택
4. SketchUp 재시작

설치되면 메뉴에 `Extensions → 모듈러 중량 Exporter`가 보입니다.

버전을 새로 받으면 같은 방법으로 다시 Install하면 덮어써집니다.

---

## 2. 전체 작업 순서 (요약)

```
1. 부재마다 그룹으로 묶기            (SketchUp 기본 기능)
2. 부재 그룹들에 ★ 빠른 부재 지정      ← 절대 빼먹지 말 것
3. 전체를 감싸는 그룹 만들기          (SketchUp 기본 기능)
4. 그 그룹에 ① 모듈로 지정
5. ⑩ 중량 데이터 검증 → 오류 확인/수정
6. ⑪ JSON 내보내기
7. 웹앱에 업로드 → Tag별 자재(단중) 등록/매핑
```

가장 흔한 실수는 **2번을 빼먹는 것**입니다. 그룹을 만드는 것과, 그 그룹에 "이건 부재다"라는 표시(role)를 붙이는 것은 완전히 별개의 두 작업입니다. 그룹만 만들어서는 아무 일도 일어나지 않습니다.

---

## 3. 메뉴 구성

`Extensions → 모듈러 중량 Exporter`

| 메뉴 | 하는 일 | 언제 쓰나 |
|---|---|---|
| **① 모듈로 지정** | 선택한 그룹을 "모듈"(전체를 감싸는 최상위 껍데기)로 지정 | 프로젝트당 한 번 (모듈이 여러 개면 그 수만큼) |
| **★ 빠른 부재 지정 (추천)** | 형상을 보고 AREA/VOLUME/LENGTH를 자동 판별 + 기준면/기준축까지 자동으로 채움 | 부재 그룹마다 (제일 많이 쓰는 명령) |
| **🔍 선택 항목 정보 보기** | 선택한 그룹의 Tag·역할·계산기준·예상 물량을 팝업으로 보여줌 (읽기 전용) | 확인하고 싶을 때 아무 때나 |
| **수동/고급 지정 →** | 아래 ②~⑫ | ★가 실패했거나 결과가 이상할 때만 |
| ② 컨테이너로 지정 | 공종별 중간 그룹 지정 (선택사항) | 잘 안 씀 |
| ③ 부재로 지정 | 계산유형을 사람이 직접 선택 | **COUNT는 항상 이걸로.** ★가 잘못 판별했을 때 재지정 |
| ④ 제외 그룹으로 지정 (IGNORE) | 계산에서 완전히 뺌 | 참고용/구버전 모델, 보조 도형 |
| ④-A 기준면·기준축 자동 채우기 | 선택한 것만, 유형은 유지하고 좌표만 새로 채움 | ③으로 유형만 바꾼 직후 |
| ④-B 기준면·기준축 전체 새로고침 | **선택 불필요**, 모델 전체를 뒤져서 좌표를 다 채움 | ③을 여러 개 했을 때 (제일 안전하고 편함) |
| ⑤ 기준면 지정 | 편집모드에서 면을 직접 클릭해서 AREA 기준 지정 | 자동 선택이 틀렸을 때 (구멍 있는 판 등) |
| ⑥ 기준축 지정 | 편집모드에서 두 점을 직접 클릭해서 LENGTH 기준 지정 | 대각선 부재처럼 자동 추정이 안 맞을 때 |
| ⑦ 무게중심 보정점 지정 | COUNT 부재의 실제 무게중심 지정 | 제조사 CG 자료가 있을 때 |
| ⑧ 부재 제외/포함 전환 | 이미 PART인 걸 껐다 켰다 | 검토 중 임시로 빼보고 싶을 때 |
| ⑫ 모델 ID 새로 발급 | 모델 고유 ID 재발급 | 거의 안 씀 |
| ⑩ 중량 데이터 검증 | 오류/경고 확인 | 내보내기 전 항상 |
| ⑪ JSON 내보내기 | 파일 저장 | 검증 통과 후 |

## 4. 단계별 상세 사용법

### 4-1. 부재 그룹 지정 (★ 빠른 부재 지정)

1. 같은 종류 부재를 **한꺼번에 선택**하는 게 제일 빠릅니다. 이미 Tag가 붙어있다면:
   - Tags 패널에서 그 Tag 이름 **우클릭 → Select Entities**
2. `★ 빠른 부재 지정` 실행
3. 창에서 **공종**만 고르면 됩니다 (Tag는 이미 있으니 비워둠)
4. 형상을 보고 자동 판별:
   - 닫힌 솔리드 → **VOLUME**
   - 얇은 판 → **AREA** (면 자동 선택)
   - 가늘고 긴 형태 → **LENGTH** (경계상자 긴 방향으로 기준축 자동 생성)
5. "판별 못했습니다"라고 나오면(주로 COUNT용 제품, 정육면체에 가까운 형상) → `③ 부재로 지정`으로 직접 선택

⚠️ **모듈 껍데기 그룹 자체에는 절대 실행하지 마세요.** (아래 6-1 참고 — 실행해도 이제는 자동으로 막아줍니다.)

### 4-2. 모듈 지정

1. 부재 그룹들 **전체를 감싸는 바깥 그룹**을 만듭니다
2. 그 바깥 그룹만 선택
3. `① 모듈로 지정` 실행

같은 파일에 서로 다른 모듈(유닛 타입 A, B 등)이 여러 개 있으면, 각각 따로 그룹으로 묶고 각각 ①을 실행하면 됩니다. 실제로 계산하고 싶지 않은 참고용/구버전 모델이 같은 파일에 남아있다면, 그건 `④ IGNORE`로 지정해서 빼주세요.

### 4-3. 검증

`⑩ 중량 데이터 검증` 실행 → 팝업에 `모듈 N개, 부재 N개, 오류 N건, 경고 N건`이 뜹니다.

- **오류(ERROR)**: 그 부재의 무게가 계산되지 않습니다. 반드시 고쳐야 함.
- **경고(WARNING)**: 계산은 되지만 참고할 사항. 급하지 않으면 무시 가능.

오류 메시지에는 **부재 이름과 Tag**가 같이 나오니, 그걸로 SketchUp에서 Select Entities로 찾아서 고치면 됩니다.

### 4-4. 내보내기 → 웹 업로드

`⑪ JSON 내보내기`로 파일 저장 → 웹앱 "업로드·검증" 탭에 업로드 → "Tag 매핑" 탭에서 각 Tag에 자재(단중) 연결.

**여기서 계산되는 건 물량(면적/체적/길이/개수)뿐입니다.** 실제 무게(kg)는 웹앱의 "자재 DB"에 등록한 단중을 곱해서 나옵니다. SketchUp에서는 단중을 입력하지 않습니다.

## 5. 실제로 자주 겪는 문제와 해결법

### 5-1. "모듈 밖에 role=PART 그룹이 있습니다" (OUTSIDE_MODULE)

부재 그룹이 모듈 그룹 **밖(형제 레벨)**에 있다는 뜻입니다. Outliner에서 그 그룹을 잘라내기(Ctrl+X) → 모듈 그룹 더블클릭해서 편집모드 진입 → 제자리에 붙여넣기(Ctrl+Shift+V)로 안으로 옮기세요.

### 5-2. ★를 실행했는데 "형상만으로 계산유형을 판별하지 못했습니다"

정상입니다 — 애매한 형상(정육면체에 가깝거나, COUNT용 제품)은 원래 자동 판별 대상이 아닙니다. `③ 부재로 지정`으로 직접 골라주세요.

### 5-3. ③으로 계산유형을 바꿨는데 "기준면/기준축이 지정되지 않았습니다" 오류가 남

③은 유형만 바꿀 뿐, 실제 좌표는 안 채웁니다. **`④-B 기준면·기준축 전체 새로고침`**을 선택 없이 한 번 실행하세요. 놓치는 것 없이 모델 전체를 한 번에 고쳐줍니다.

### 5-4. 웹앱에서 같은 Tag인데 일부는 "OK", 일부는 "미산출(UNRESOLVED)"

**같은 Tag를 쓰는 부재들 중 일부만 계산유형이 다르게 잡혀있다는 뜻**입니다 (예: 대부분 LENGTH인데 몇 개는 VOLUME). SketchUp에서 문제되는 개수만큼:
1. `🔍 선택 항목 정보 보기`로 실제 계산유형이 뭔지 확인
2. 그 Tag 전체를 Select Entities → `③ 부재로 지정`으로 올바른 유형으로 강제 통일
3. `④-B` 실행 → `⑩` 재검증 → `⑪` 재내보내기 → 웹앱 재업로드

### 5-5. 웹앱 대시보드에 "INCOMPLETE"와 "미해결 N건"이 뜸

SketchUp 쪽 문제가 아니라 **웹 자재 DB에 아직 그 Tag의 단중을 등록/매핑 안 한 것**입니다. "부재 목록" 탭에서 상태를 "미산출"로 필터링 → 어떤 Tag가 남았는지 확인 → "자재 DB"에서 등록 → "Tag 매핑"에서 연결.

### 5-6. Tag 이름에 소문자 x가 있다고 경고(UNCLASSIFIED)가 뜸

`200x150x12`처럼 치수 표기에 쓰는 소문자 x 때문입니다. 계산에는 지장 없는 경고일 뿐이니 무시해도 됩니다.

### 5-7. 모듈 그룹 자체의 role이 실수로 바뀜

MODULE로 지정된 그룹은 ②③④★가 자동으로 보호합니다(실행해도 건너뛰고 "보호되어 건너뛰었습니다"라고 알려줌). 다만 **④ IGNORE만은 예외적으로 모듈에도 적용 가능**합니다 — 모듈 전체를 통째로 계산에서 빼고 싶을 때 의도적으로 쓰는 경우이기 때문입니다.

## 6. 자주 헷갈리는 개념 정리

| 헷갈리는 것 | 정리 |
|---|---|
| 그룹 만들기 vs 부재로 지정 | 그룹 만들기 = SketchUp 기본 기능(형상 묶기). 부재로 지정(★/③) = 우리 도구의 표시(role) 붙이기. **둘 다 해야 계산됩니다.** |
| 공종(STRUCTURE 등) | 리포트 분류용일 뿐, 무게 계산 자체에는 영향 없음. 몰라도 OTHER로 두고 넘어가도 무방 |
| Tag = 자재 이름 | Tag는 SketchUp 기본 Tag(레이어) 기능을 그대로 씁니다. 웹 자재 DB의 "이름"과 SketchUp Tag는 똑같을 필요 없음 — 웹에서 드롭다운으로 직접 연결하기 때문 |
| 단중은 어디서 입력하나 | SketchUp이 아니라 **웹앱 자재 DB**에서 입력합니다. SketchUp은 물량(면적/체적/길이/개수)만 계산합니다 |
| ③과 ④-A/④-B의 차이 | ③ = 계산유형을 바꿈(좌표는 안 건드림). ④-A/B = 좌표(기준면/기준축)만 채움(유형은 안 건드림). 보통 ③ 다음에 ④-B를 씁니다 |

---

## 7. 실무 팁

- **처음부터 Tags 패널의 "Select Entities"를 적극 활용하세요.** Outliner에서 하나씩 찾는 것보다 훨씬 빠르고, 모듈 껍데기가 실수로 선택될 위험도 없습니다.
- 형상이 복잡한 대형 프로젝트에서는 ★ 한 번으로 다 안 끝날 수 있습니다 (같은 Tag라도 개별 형상 차이로 판별이 갈릴 수 있음) — 이럴 땐 5-4번 절차로 마무리하세요.
- 콘크리트처럼 VOLUME으로 계산하는 자재는 웹 자재 DB에서 **"비중으로 입력"** 모드를 쓰면 밀도값(예: 철근콘크리트 2.4)만 넣어도 자동으로 kg/m³ 단중이 계산됩니다.
